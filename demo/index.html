            02 / The mechanism
            
Observe. Freeze. Validate.
Then publish, atomically.

          

          

            No model judges the merge. Ordinary programs run through a FUSE
            mount; deterministic checks decide whether their recorded inputs are
            still current.

          04 / What this does and doesn't establish
          
Remembering reads
isn't understanding intent.

        

        

          

            The useful guarantee is narrow: recorded base-state dependencies
            still match at acceptance. Previous conversations, network
            responses, host files and unobserved assumptions remain outside it.
          

          

            Whole-file reads can reject harmless changes. Broad searches can
            create large read sets. This is an experimental workspace component,
            with real overhead and no production adoption yet.
          

          

            Optimistic transactions and transactional filesystems have decades
            of prior art.
            Zit, BranchFS, AgentFS and others
            inform the comparison. WitnessFS explores transparent filesystem
            observations and a testable acceptance boundary.
